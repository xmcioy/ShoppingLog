# 展望（Roadmap）

方向按「能省时间 / 能省钱 / 数据更安全」排序，做完一条划一条，具体落哪个版本不预设。
实际进展以 [CHANGELOG.md](CHANGELOG.md) 为准。

## 近期

- [ ] **价格曲线**：同一商品的历史价格画成折线图（数据已在 `purchases` 里，只差可视化）。
- [ ] **到期提醒**：食品 / 保健品的到期日在首页置顶提醒（`expiry_date` 已有）。
- [ ] **复购建议**：按「买过 N 次 + 会回购」生成回购清单，附上次价格与渠道。
- [ ] **批量编辑**：表格视图里直接改价格 / 分类 / 标签，不用逐条开弹窗。

## 中期

- [ ] **移动端优化**：小屏下单列卡片 + 底部操作条；拍照上传走系统相机。
- [ ] **导出与备份**：一键导出 CSV / JSON 全量备份，含图片打包；定时备份到对象存储。
- [ ] **OCR 增强**：条码 / 二维码识别直接补全商品；多页订单截图的结构化抽取。
- [ ] **家庭 / 共享账号**：同一商品下聚合多个人的评价（公开广场已按商品分组，只差权限模型）。

## 长期

- [ ] **多币种与汇率**：跨境购买按币种分别统计（`currency` 字段已预留）。
- [ ] **预算与分类上限**：月度预算、分类预算，超支提醒。
- [ ] **插件化品类**：品类与扩展字段由配置驱动，加品类不改代码。
- [ ] **只读分享链接**：给单条记录生成带过期时间的分享页。

## 明确不做

- 接外部大模型 API 做识别（本项目坚持本地 OCR + 规则评分，零外传）。
- 引入前端框架与构建链（页面保持单文件静态 HTML，部署只要 nginx）。
